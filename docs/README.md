# MAAPS Dokumentation

Willkommen in der Dokumentation für **MAAPS** (*Machine Access And Payments System*).

Die Dokumentation ist in zwei Hauptbereiche unterteilt:

- [📖 Benutzerhandbuch (User Guide)](user_guide.md): Anleitung für Mitglieder, Maker, Kassenwarte und Administratoren zur Nutzung von Maschinen, POS-Terminals und dem Web-Interface.
- [🛠️ Entwicklerhandbuch (Developer Guide)](dev_guide.md): Technische Dokumentation der Architektur, Datenmodelle, Hardware-Ansteuerung, API-Schnittstellen und Installation/Provisionierung.
- [📋 System Claims & Feature Specification](claims.md): Übersicht aller abzusichernden Systemverhaltensgarantien, Features und Spezifikationen als Grundlage für die Testsuite.
